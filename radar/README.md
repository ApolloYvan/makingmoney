# 机会雷达 · 第一阶段

这个目录是机会雷达第一阶段的全部内容：规则、数据、访谈记录和每周的周报。为什么做、怎么设计，见仓库根目录的《机会雷达双Agent策划案.md》，第七节专门讲这个阶段。

一句话说明：每周日晚上，Claude 按来源清单去找信号、整理进 CSV；`score.py` 按规则算分、生成周报；GPT 给前几名挑毛病；我挑一两个方向去线下验证，结果再写回来。

## 目录

```
radar/
  README.md              本文件
  规则/                   只有我能改
    来源清单.csv           查哪些来源；"一期"为"是"的是第一阶段要查的
    打分规则.toml          所有选项的写法、换算表、交汇系数、门槛
    不碰的事.md
    每周采集指令.md         给 Claude 的固定指令
    复核指令.md            给 GPT 的固定指令
    score.py              打分脚本，只用 Python 标准库
  数据/                   信号只追加；方向和政策由 Claude 维护，验证由我填
    信号.csv
    方向.csv
    政策.csv
    验证.csv
  访谈/                   每次访谈一个文件，模板见 _模板.md
  周报/                   每周一期，如 2026-W42.md；每月一份行业压力，如 2026-10-行业压力.md
  tests/                 score.py 的测试
```

## 第一个周末要做的事

1. 把 `规则/来源清单.csv` 里"入口"为空、备注写着"由我补充"的几行补上具体网址，尤其是"本省市申报通知"（填我所在省市的经信、发改、数据局）和"国内模型厂商价格和公告"。
2. 通读 `规则/打分规则.toml` 和 `规则/不碰的事.md`，按自己的判断调整档位。
3. 确认 Python 版本在 3.11 以上（`python3 --version`），然后跑一遍测试：`python3 -m unittest discover -s radar/tests`。本机 Python 太旧的话，可以用 uv：`uv run --python 3.12 radar/规则/score.py`。
4. 按下面"每周怎么跑"跑第一期。第一次没有历史周报，Claude 会回看最近 30 天。
5. 把规则的改动和第一期的数据一起提交到 git。

## 每周怎么跑

每周日晚上，大约 1 小时：

1. 在 Claude 桌面端打开这个仓库，发一句"请按 `radar/规则/每周采集指令.md` 跑本周的采集"。
2. 它跑完以后看 git diff：`规则/` 有没有被动过（动过就撤回）；新增的信号是不是每条都有链接和原文摘录。
3. 如果 Claude 没有自己生成周报，就运行 `python3 radar/规则/score.py`。
4. 随机点开 5 条证据链接，核对摘录是不是原文。
5. 打开 GPT，按 `规则/复核指令.md` 复核前几名，把复核意见贴进周报最后一节。
6. 挑 1 到 2 个方向，安排这周的访谈或定金测试；需要的话，把方向的状态改成"验证中"。
7. 确认无误后 git commit。

每月第一个周日，Claude 会额外生成一份行业压力表。

## 访谈以后

1. 用手机录一段语音，用 Claude 或 GPT 的 App 转写，按 `访谈/_模板.md` 整理，存成 `访谈/日期-行业.md`。下次采集时 Claude 会把它整理成信号。
2. 在 `数据/验证.csv` 里加一行：日期、方向编号、方式（访谈或定金测试）、结果（确认痛点、有人付定金、未确认、否定）、证据（访谈文件名）。
3. 结果明确的，把 `数据/方向.csv` 里这个方向的状态改成"通过"或"否决"。

## 几条约定

- 分数只由 `score.py` 算，周报里的分数不要手改。规则一改，所有方向都会按新规则重算。
- 选项类的字段只能用 `打分规则.toml` 里列出的写法，一个字都不能差。
- CSV 用 UTF-8 编码。用 Excel 或 WPS 打开、保存时，注意保持 UTF-8 格式和原来的列顺序。
- 访谈记录里不写姓名、电话和公司名。
- 换了模型或客户端，照这一套文件继续跑就行，不依赖任何聊天记录。

## 常用命令（在仓库根目录运行）

```
python3 radar/规则/score.py                    以今天为截止日生成周报
python3 radar/规则/score.py --date 2026-10-18  指定截止日
python3 radar/规则/score.py --check            只检查数据，不生成周报
python3 -m unittest discover -s radar/tests    跑测试
```
