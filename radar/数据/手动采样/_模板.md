# 手动采样记录模板

需要登录、或者程序不让看的平台，由我手动看。哪周要看哪几个，见 `radar/每周清单.md`。

怎么存：每周建一个文件夹，名字和周报一样，例如 `数据/手动采样/2026-W42/`；每个来源复制一份这个模板放进去，文件名就是来源清单里的名称，例如 `闲鱼.md`、`猪八戒.md`、`BOSS直聘.md`。以下划线开头的文件是模板，采集时会跳过。下次采集时，Claude 会把这里的每一条整理成信号。

怎么看：严格按 `规则/来源清单.csv` 里这个来源的"取样方法"看，固定的页面、固定的条数。只记和"有人在为某件事付钱"有关的条目，不用挑主题，看到什么记什么。一条都没记也要写上"看了多少条，记了 0 条"。

怎么记：照抄就行，不用分析。金额一栏填看到的价格、预算或薪资；热度一栏填销量、"想要"人数、投标人数、订购人数、成员数，看到哪个填哪个；补充一栏放岗位职责里的具体工作、差评原文、类目这类信息。实在没时间，手机截图放进同一个文件夹也行，文件名写成 `来源-序号.jpg`。
